## 💡 Sobre el Proyecto
Plan Z es una aplicación móvil (próximamente) que ofrece planes de alimentación personalizados generados mediante IA, combinados con descuentos reales (del 10% al 25%) en restaurantes y establecimientos locales. 

El objetivo de esta página web es **validar el mercado**, captar usuarios interesados a través de una lista de espera y servir como carta de presentación para restaurantes aliados (B2B).

## ✨ Características de la Página Web
*   **Diseño 100% Responsivo:** Adaptado para móviles, tablets y computadoras.
*   **Menú Hamburguesa:** Navegación fluida sin necesidad de JavaScript.
*   **Sección FAQ:** Acordeón interactivo para resolver dudas de los usuarios.
*   **Formulario de Lista de Espera:** Integración con Formspree para captar correos reales.
*   **Scroll Suave:** Navegación fluida entre secciones.
*   **Páginas Legales:** Aviso de Privacidad y Términos y Condiciones (conforme a la LFPDPPP).
*   **SEO Básico:** Meta tags y Open Graph configurados para compartir en redes sociales.

## 🛠️ Tecnologías Utilizadas
*   **HTML5:** Estructura semántica de la página.
*   **CSS3:** Estilos, diseño responsivo (Flexbox y Grid), variables de color y animaciones.
*   **Formspree:** Servicio para recibir los correos del formulario sin necesidad de un backend propio.
*   **GitHub Pages:** Hosting gratuito para el sitio web estático.
